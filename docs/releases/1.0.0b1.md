# Excel AI Assistant 1.0.0b1 — beta

A desktop app for supervised AI text transformations in selected Excel and CSV cells. Generate proposals with optional context, review them, apply selected changes and save explicitly.

## Installation

Install Python 3.13 or 3.14 with Tkinter, create and activate a virtual environment, then download the wheel asset from this release:

```powershell
python -m pip install ./excel_ai_assistant-1.0.0b1-py3-none-any.whl
excel-ai-assistant --check-install
excel-ai-assistant
```

Runtime dependencies download from your configured Python package index. This release contains Python distributions, not a standalone executable or signed operating-system installer. An AI provider/account or your own Ollama server is required for generation. Never share your API key in an issue or workbook.

## Included

- Review/select/apply/discard, send confirmation, cancellation and result export.
- OpenAI, OpenRouter and Ollama provider selection with separate cloud credentials and model preferences. OpenRouter keys may be entered in the toolbar or Preferences, or supplied through `OPENROUTER_API_KEY`.
- Worksheet selection and saves that patch cells while preserving unrelated workbook package parts.
- Formula-as-text and CSV protections, source conflict detection, atomic writes, backups, undo and recovery snapshots.
- Package diagnostics, representative workbook coverage and GitHub release artifact checks.

## Known limitations

Development beta for modest files with a header row, not a full Excel editor or calculation engine. No macro execution, formula calculation, table resizing or pivot/connection refresh. Protected sheets, document signatures and computed/rich output cells may block saves. VBA and advanced opaque parts have package preservation tests; genuine customer macros and Microsoft Excel runtime behavior remain unverified. AI output requires human review; no guaranteed accuracy, enforceable spending cap, durable job recovery or audit history is provided.

Local installation evidence covers isolated Windows Python 3.14 using cached wheels and a sandbox temporary-directory adapter. Normal GitHub runner installations, advisory scanning, live providers, Python 3.13 and Linux must be confirmed by release checks and smoke tests. macOS remains unverified. The historical uv lock is not the recommended installation path.

Before publication, update the release body with the successful GitHub run link and any remaining platform/provider limitations. SHA256SUMS and release-check.json describe the distribution assets; checksums alone do not provide publisher authentication.
